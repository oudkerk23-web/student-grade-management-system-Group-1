## Description: 
(CS 155 final project) Menu-driven Java program that stores student names and grades
in parallel 1D arrays (max 50 students). It can add students, display all records, search a grade by name, 
calculate the class average and find the highest and lowest grades.

## How to Compile and Run
  javac StudentGradeManagementSystem.java
  java StudentGradeManagementSystem

Or import the file into Eclipse and run it.
